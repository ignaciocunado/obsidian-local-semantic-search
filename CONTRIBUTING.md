# Contributing Guide

Thank you for your interest in contributing to this Obsidian Local Semantic Search! Contributions of all kinds are welcome, whether it's reporting bugs, suggesting features, improving documentation, or writing code.

---

## 🚀 Getting Started

1. **Fork the repository**
2. **Clone your fork**

   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   cd your-repo-name
   ```
3. **Install dependencies**

   ```bash
   npm install
   ```
4. **Run the development build**

   ```bash
   npm run dev
   ```

Make sure you have a working Obsidian vault set up for testing your changes.

---

## 🛠 Development Guidelines

* Write clean, readable, and well-documented code.
* Follow the existing code style and structure.
* Keep commits small and focused.
* Use meaningful commit messages.

If you're unsure about a change, feel free to open an issue or discussion first.

---

## 🧪 Testing

* Test your changes in Obsidian before submitting a pull request.
* Check for edge cases and potential regressions.
* If applicable, include steps to reproduce bugs or verify fixes.

---

## 🐛 Reporting Bugs

When reporting bugs, please include:

* A clear and descriptive title
* Steps to reproduce the issue
* Expected vs actual behavior
* Screenshots (if applicable)
* Your environment (OS, Obsidian version, plugin version)

---

## 💡 Suggesting Features

Feature requests are welcome! Please include:

* A clear description of the feature
* The problem it solves or the use case
* Any alternative solutions you've considered

---

## 🔀 Pull Requests

Before submitting a pull request:

* Ensure your branch is up to date with `main`
* Run builds and verify everything works
* Provide a clear description of your changes

PRs should:

* Address a single concern
* Reference related issues (if any)
* Include screenshots or demos if relevant

---

## 📚 Code Style

* Use consistent formatting (Prettier/ESLint if configured)
* Prefer descriptive variable and function names
* Add comments where necessary, but avoid obvious comments

---

## 🤝 Community Guidelines

* Be respectful and constructive
* Assume good intent
* Help others learn and grow
